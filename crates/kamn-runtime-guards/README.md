# kamn-runtime-guards

## Purpose
Extracted runtime guard and policy modules used by `kamn-core` and node execution flows.

## Key Surfaces
- `anti_spam`
- `fairness_policy`
- `message_delivery_guards`
- `quota_policy`
- `retention_engine`
- `watchdog`

## Usage
- Build: `cargo build -p kamn-runtime-guards`
- Test: `cargo test -p kamn-runtime-guards`

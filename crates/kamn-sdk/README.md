# kamn-sdk

## Purpose
Rust SDK surface for interacting with KAMN transports and domain types.

## Key Surfaces
- `agent`
- `error`
- `live`
- `memory`
- `service`
- `tcp`
- `types`

## Usage
- Build: `cargo build -p kamn-sdk`
- Test: `cargo test -p kamn-sdk`

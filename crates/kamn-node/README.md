# kamn-node

## Purpose
Node runtime binary for bootstrapping, orchestration, service API, and live transport execution.

## Key Surfaces
- `cli`
- `daemon_observability`
- `daemon_shutdown`
- `kolme_live_observability`
- `logging`
- `observability_endpoint`
- `report_builder`
- `report_render`
- `runtime_kolme_live`
- `runtime_orchestration`
- `service_api_endpoint`
- `signer`
- `wire_payload`
- `cli_tests`
- `main_tests`

## Usage
- Build: `cargo build -p kamn-node`
- Test: `cargo test -p kamn-node`

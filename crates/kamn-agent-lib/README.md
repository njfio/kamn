# kamn-agent-lib

## Purpose
Shared phase-1 agent library for authenticated KAMN operations.

## Key Surfaces
- `auth`
- `client`
- `envelope`
- `errors`
- `identity`
- `kolme`
- `nonce`

## Usage
- Build: `cargo build -p kamn-agent-lib`
- Test: `cargo test -p kamn-agent-lib`
